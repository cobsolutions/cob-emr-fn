Instructions

This scale is used to assess pain intensity by selecting the face that best describes how you feel.

  • Look at each face and select the one that best describes how you are feeling right now
  • Face 0 is very happy because there is no hurt at all
  • Face 5 hurts as much as you can imagine, although you do not have to be crying to feel this bad

Scoring: The selected face value (0-5) represents the pain rating.
