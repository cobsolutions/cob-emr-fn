Fullerton Advanced Balance (FAB) Scale

Instructions

Description: The Fullerton Advanced Balance (FAB) Scale is a 10-item test designed to measure static and dynamic balance in functionally independent older adults.

Equipment needed:

  • Pencil
  • Stopwatch
  • 6-inch bench
  • 12-inch ruler
  • 6-inch high-density foam (Airex balance pad or equivalent)
  • Tape measure
  • Masking tape

Scoring: Each item is scored 0-4 points. Total score ranges from 0-40.

Evaluating Risk for Falls:

  • Long Form FAB Scale Cut-Off Score: ≤ 25/40 Points
  • Short-Form FAB Scale Cut-Off Score: ≤ 9/16 Points
