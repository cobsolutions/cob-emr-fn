Knee injury Osteoarthritis Outcomes Score (KOOS)

Instructions

This survey asks for your view about your knee. This information will help us keep track of how you feel about your knee and how well you are able to do your usual activities. Answer every question by selecting the appropriate option, only one option for each question. If you are uncertain about how to answer a question, please give the best answer you can.

Scoring:

To calculate the KOOS, score each question by assigning a zero to the left most answer, a one to the next answer to the right, two for the next, three for the next, and a four for the rightmost answer. Then each subscale is calculated separately:

  • Pain = 100 - ((P1 + P2 + ... + P9) / 9) x 100 / 4
  • Symptoms = 100 - ((S1 + S2 + ... + S7) / 7) x 100 / 4
  • ADL = 100 - ((A1 + ... + A17) / 17) x 100 / 4
  • Sport/Rec = 100 - ((SP1 + SP2 + SP3 + SP4 + SP5) / 5) x 100 / 4
  • QOL = 100 - ((Q1 + Q2 + Q3 + Q4) / 4) x 100 / 4
  • Composite Score (KOOS5) = (Pain + Symptoms + ADL + Sport/Rec + QOL) / 5

Interpretation:

G-Code Modifiers are assigned by the Composite Score as follows:

  • 100 = CH
  • 81 - 99 = CI
  • 61 - 80 = CJ
  • 41 - 60 = CK
  • 21 - 40 = CL
  • 1 - 20 = CM
  • 0 = CN
